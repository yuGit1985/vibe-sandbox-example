This repository is an experimental sandbox for structured executable prototypes created with coding agents. It is not a production-ready application template.

## Getting Started

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) and sign in with the fixed in-memory prototype account:

- Email: `kenta.takahashi@orbit.jp`
- Password: `orbit-demo`

The credentials and session adapter are intentionally prototype-only and must be replaced before production use.
